## 1. 产品定位

一款 Android 汇率换算计算器 App：把「汇率查询」与「金额计算」合并在一页计算器内，打开即用、完全离线可用，网络仅用于后台更新汇率。

## 2. 目标用户

- 有跨境消费、旅行、汇款、海外购物、留学等场景，需要在本国货币与目标国货币之间快速换算金额的用户
- 不愿注册账号、不依赖复杂金融工具，追求即开即用的普通用户

> 说明：以上基于产品定位整理，具体用户画像待 Product Owner 补充确认。

## 3. 核心使用场景

1. 出行前 / 境外付款前，快速算出「这个金额折合人民币（本地货币）是多少」
2. 直接在计算器上输入金额，即时看到目标货币换算结果，无需二次操作
3. 无网络（飞行模式、境外断网）时依然可以完成换算（使用缓存的汇率）

## 4. 核心价值

- **一页式**：计算器 + 汇率换算在同一页面完成，无页面跳转
- **零门槛**：无账号、无强制引导以外的任何设置
- **离线优先**：核心换算功能 100% 离线可用
- **轻量**：控制包体积，安装即用

## 5. 产品形态与首屏

- **一页式计算器设计**：整个 App 的核心就是一页
- **App 打开后直接进入计算器**，无启动页跳转、无首页
- **不存在顶部 App Bar**：
  - 不显示「汇率计算器」顶部标题
  - 不存在顶部右侧信息按钮
  - 不存在顶部右侧三点菜单

## 6. 功能需求（FR）

### FR-1 货币行
- 两行货币区：
  - 第一行：当地 / 当前输入货币
  - 第二行：目标 / 熟悉货币
- 左侧显示国旗 / 货币识别；右侧显示金额
- 两行之间有分隔线；两行中间有 ⇅ 交换按钮
- **本地货币**：默认基于设备地区确定（具体判定规则待确认，见 §12）
- **常用 / 熟悉货币**：第二行默认货币（默认值规则待确认，见 §12）

### FR-2 货币选择
- 用户可以更换第一行 / 第二行的货币
- 可选范围：V1 首发支持 15 种货币（见 FR-5）

### FR-3 货币交换（⇅）
- 点击 ⇅ 交换两行货币（输入货币 ↔ 目标货币）

### FR-4 计算器（5×4 键盘）
- 5 行 × 4 列键盘，右侧第四列为运算符列
- 支持运算符：`+` `-` `×` `÷` `=`
- `C`：清空
- `⌫`：删除一位；**长按删除**连续删除
- `%`：百分比
- 删除键 ⌫ 按当前已确认设计占用两个单元格（布局详见 UI-SPECIFICATION-V1.0.md）

### FR-5 首发货币（15 种）
USD、EUR、CNY、JPY、GBP、HKD、TWD、KRW、SGD、AUD、CAD、CHF、PLN、THB、INR

- 使用标准 ISO 4217 货币代码
- 货币逻辑不得写死在 UI（详见 CURRENCY-SPECIFICATION-V1.0.md）
- 架构必须支持未来增加货币

### FR-6 即时换算
- 输入 / 运算过程中，第二行（目标货币）**即时**显示换算结果，无需按等号触发换算

### FR-7 汇率数据
- **离线计算**：核心换算完全离线可用
- **汇率缓存**：最近一次成功获取的汇率持久化到本地
- **在线更新**：有网络时更新汇率
- **底部刷新**：底部左侧 ↻ 按钮手动触发刷新

### FR-8 底部信息栏
- 底部左侧：↻ 刷新按钮
- 底部中间：**汇率更新时间**
- 更新时间下方：**当前汇率**（例如 `1 JPY = 0.04848 CNY`）
- 汇率文字**不可点击**
- 底部右侧：**•••** 更多信息入口（不使用「更多」文字按钮，不使用右箭头）

### FR-9 更多信息页面
- 通过底部右侧 ••• 进入
- 页面内容至少包括：关于、隐私政策、用户协议、用户反馈入口
- 「Google Play 官方评价」入口（使用 Google Play 官方 In-App Review API）
- 详细内容项见 §12 待确认清单

### FR-10 首次启动引导
- 首次启动显示引导（引导内容与形式待确认，见 §12）

### FR-11 国际化
- **六种首发语言（已正式锁定，OQ-01 已关闭）**：简体中文、English、日本語、Deutsch、Français、Español
- 所有界面文字支持国际化，不允许硬编码文案

### FR-12 主题
- 跟随系统浅色 / 深色模式
- **不提供** V1 手动主题切换

### FR-13 Push 通知
- V1 包含 Push 能力（Push 的具体业务场景、触发规则、供应商选型**待确认**，见 §12）

### FR-14 Google Play 官方评价
- 使用 Google Play 官方 In-App Review API 发起评价（不由 App 自建评分体系）

### FR-15 用户反馈
- 提供用户反馈入口（反馈方式待确认，见 §12）

### FR-16 关于 / 隐私政策 / 用户协议
- 「关于」页展示应用信息
- 提供隐私政策、用户协议的查看入口（文档内容与托管方式待确认，见 §12）

### FR-17 Analytics
- V1 包含 Analytics 统计（事件范围与供应商选型**待确认**，见 §12）

## 7. 非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 性能 | 启动时**绝不能等待网络**；首屏进入计算器无感延迟（具体性能指标待确认） |
| 包体积 | 严格控制包体积（具体目标值待确认）；最少第三方依赖 |
| 隐私 | **无账号体系**，不要求注册登录；权限遵循最小权限原则 |
| 离线 | 计算器核心功能必须可以完全离线工作；Offline First 架构 |
| 兼容 | 跟随系统浅色 / 深色模式；min / target SDK 见架构文档 |

## 8. UI 最终确认规则（红线，不得更改）

以下为已确认的最终 UI 规则，实现必须严格遵守：

1. 不存在顶部 App Bar
2. 不显示「汇率计算器」顶部标题
3. 不存在顶部右侧信息按钮
4. 不存在顶部右侧三点菜单
5. App 打开后直接进入计算器
6. 底部左侧为刷新（↻）
7. 底部中间显示汇率更新时间
8. 更新时间下方显示当前汇率
9. 汇率文字不可点击
10. 底部右侧为 •••（更多信息）
11. 不使用「更多」文字按钮
12. 不使用右箭头作为更多入口

## 9. V1 不做事项

- ❌ 手动主题切换（仅跟随系统）
- ❌ 账号 / 登录体系
- ❌ 顶部导航栏、顶部菜单
- ❌ 首发货币（15 种）以外的货币选择
- ❌ 其余排除项以 ChatGPT 与 Product Owner 确认的版本为准；如实现中发现歧义，记录并暂停
