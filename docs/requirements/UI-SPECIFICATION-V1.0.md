## 1. 页面总览

App 主体为**单页计算器**（一页式设计），自上而下分为三个区域：

```
┌─────────────────────────────┐
│ （无 App Bar / 无标题 / 无菜单）│   ← 顶部：什么都不放
├─────────────────────────────┤
│  🇯🇵 JPY        12,345      │   ← 货币行 1（输入货币）
│──────────────⇅──────────────│   ← 分隔线 + 交换按钮
│  🇨🇳 CNY           597.9    │   ← 货币行 2（目标货币）
├─────────────────────────────┤
│  C    ⌫ ⌫            ÷     │
│  7    8    9          ×     │
│  4    5    6          −     │
│  1    2    3          +     │
│  0    .    %          =     │   ← 计算器 5×4
├─────────────────────────────┤
│ ↻      2026-09-30 11:20     │   ← 底部信息栏
│        1 JPY = 0.04848 CNY  │
│                     •••     │
└─────────────────────────────┘
```

## 2. 顶部区域

- **无 App Bar**
- **无标题**（不显示「汇率计算器」文字标题）
- **无顶部右侧信息按钮**
- **无顶部右侧三点菜单**

## 3. 货币区域

| 元素 | 规则 |
|---|---|
| 第一行 | 当地 / 当前**输入**货币：左侧国旗 + 货币识别（代码），右侧金额（用户输入 / 计算结果） |
| 第二行 | 目标 / **熟悉**货币：同一布局，金额为**即时换算结果**（只读展示） |
| 分隔线 | 两行之间有分隔线 |
| ⇅ | 位于两行之间（中间），点击交换两行货币 |
| 国旗/货币识别 | 左侧显示；显示逻辑与货币数据模型分离（见 CURRENCY-SPECIFICATION-V1.0.md） |

## 4. 计算器键盘（5 行 × 4 列）

**已确认布局：**

| 行 \ 列 | 列 1 | 列 2 | 列 3 | 列 4（运算符列） |
|---|---|---|---|---|
| 行 1 | `C` | `⌫`（跨两格） | `⌫`（跨两格） | `÷` |
| 行 2 | `7` | `8` | `9` | `×` |
| 行 3 | `4` | `5` | `6` | `−` |
| 行 4 | `1` | `2` | `3` | `+` |
| 行 5 | `0` | `.` | `%` | `=` |

**键位行为：**

| 键 | 行为 |
|---|---|
| `C` | 清空当前输入 |
| `⌫` | 删除一位；**长按**连续删除（按当前设计占用两个单元格） |
| `+` `−` `×` `÷` | 四则运算 |
| `=` | 计算结果 |
| `%` | 百分比（与四则运算的组合语义详见 PRD / 计算引擎实现时确认，不得自行扩展） |
| 数字 / `.` | 输入整数与小数 |

> 数字区域固定为 `7 8 9 / 4 5 6 / 1 2 3 / 0 . %`。

## 5. 底部信息栏

| 位置 | 元素 | 规则 |
|---|---|---|
| 左 | ↻ | 手动刷新汇率 |
| 中 | 汇率更新时间 | 显示最近一次汇率成功更新的时间 |
| 中（更新时间下方） | 当前汇率 | 例如 `1 JPY = 0.04848 CNY`；**不可点击**，无点击态 |
| 右 | `•••` | 进入「更多信息」页面的**唯一**入口 |

**红线：**
- 不使用「更多」文字按钮
- 不使用右箭头（→ / ›）作为更多入口
- 汇率文字不可点击

## 6. 颜色与主题

- 跟随系统**浅色 / 深色**模式
- **不提供** V1 手动主题切换入口
- 具体色板、字体、间距等视觉参数：以 Product Owner 已确认的设计为准；如需代码化（Color Token 等），在实现阶段按已确认设计落图，**不得自行新配色**

## 7. 国际化

- 所有界面文字（含无障碍描述、错误提示）必须来自字符串资源，支持国际化
- 首发支持六种语言（已正式锁定）：简体中文、English、日本語、Deutsch、Français、Español
- 货币显示名称使用本地化名称（见 CURRENCY-SPECIFICATION-V1.0.md）

## 8. 预留扩展

- 键盘与页面结构**预留未来扩展能力**（如结构上的可扩展位），但 **V1 不显示任何未来功能入口**
